# Demo Script

## 1. Start the system
- Run backend
- Run frontend
- Open Dashboard

## 2. Show document ingestion
- Upload one TXT file
- Upload one DOCX file
- Upload one PDF file
- Add one manual text input

Explain:
- files are stored
- text is extracted
- metadata is saved in SQLite

## 3. Show document vs document comparison
- Open Compare page
- Select two similar documents
- Run comparison
- Explain similarity percentage
- Explain top matching sentences
- Export PDF report

## 4. Show one-vs-corpus analysis
- Open Corpus Check page
- Select one document
- Show ranked similar candidates

## 5. Show batch checking
- Open Batch Check page
- Select several documents
- Show suspicious pairs

## 6. Show similarity graph
- Open Graph page
- Generate graph for all documents
- Explain nodes and edges

## 7. Show intrinsic style-shift detection
- Open Reports page
- Run style-shift analysis
- Explain suspicious chunks and anomaly score

## 8. Show dashboard management
- Go back to Dashboard
- Show summary
- Delete one document
- Optionally use reset-all tool
